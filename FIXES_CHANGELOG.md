# Исправления багов в маркетплейсе

## Баг #1: Удалить логику самопродажи (покупатель = продавец)
**Проблема:** Когда я покупаю товар, вместо взаимодействия с другим пользователем происходит самопродажа. Должна быть кнопка "Оформить доставку" → адрес отправляется боту → бот (продавец) отправляет код доставки.

**Что нужно исправить:**
- Удалить функцию, которая позволяет покупателю быть самому себе продавцом
- Оставить только корректный сценарий: покупатель ≠ продавец
- Убрать логику "я оформляю доставку для себя самого"

## Баг #2: Согласовать характеры с именами персонажей
**Проблема:** На скрине видно, что у Дениса характер "бабушка" (говорит как бабушка). Характеры должны совпадать с именами.

**Что нужно исправить:**
- Если характер = "бабушка", то имя должно быть соответствующее (Людмила, Галина и т.д.)
- **Убрать характер "бабушка" у продавцов дорогих товаров** (машины, квартиры и т.д.)
- Оставить характер "бабушка" только у розничных продавцов простых товаров
- Шанс появления "бабушки" у продавца должен быть небольшим
